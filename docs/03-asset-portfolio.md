## 2. 优先级

**优先转化**：MODEL-01、02、05、07、08、09、11、12、13、15。它们已经有产品链路、专利或参赛资料能力描述，适合先做固定场景验收。

**优先补证据**：MODEL-03、04、06、10。它们已有专利或研究依据，但需要权利要求映射、独立测试集和实际任务验证。

**按课题推进**：MODEL-14 以及研究院课题 01–04、07–19。课题状态不等于模型完成状态。
