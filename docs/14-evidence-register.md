# 证据登记与缺口

## 1. 证据等级

| 等级 | 含义 | 当前能写的结论 |
| --- | --- | --- |
| E0 | 课题或产品设想 | 拟研究、待验证 |
| E1 | 工程流程、软件承载或登记材料 | 已形成基础、具备承载条件 |
| E2 | 专利/研究材料或受控样例 | 有技术依据，可进入受控验证 |
| E3 | 独立复现和目标区域验证 | 可申请小范围试点 |
| E4 | 产品或现场验收、持续监控 | 可写已验收或持续运营 |

## 3. 缺口处理

缺口按数据授权、结果复现、工程稳定、现场真值和法律权属五类登记。每项缺口需要责任人、截止时间、验收条件和失败降级方案。没有证据时保留“待核验”，不根据标题、接口或单张演示图推断成熟度。
