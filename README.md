## 本版范围

- 聚焦农业生产平台、遥感、地块评估、农业智能体、农资与测土报告识别、无人机作业协同、研究成果和知识产权。
- 公开版只保留技术能力和证据边界，不公开本地路径、仓库位置、分支、提交号、内部地址、配置值或源代码位置。
- 本版只保留本技术负责人负责的其他技术方向，范围以本页和目录中的十条能力线为准。
- 开放课题保留与本技术负责人相关的 16 项；其中 05、06 明确为未启动，其余按用户确认标记为已开始规划。
- 当前包含 7 项专利事项、4 项软件著作权、FieldBCQ 和 Wheat-KGCA 两项研究成果，以及 7 张新的公开位图信息图。

## 证据口径

文档把“已有工程能力”“历史研究结果”“独立复现实验”“产品验收”和“田间效果”分开。源码或接口存在，只能说明形成了工程基础；论文或历史报告中的指标，只能说明指定数据和版本下有结果；没有把它们直接写成当前线上精度或现场增益。

公开仓库适合评审技术方向和下一步工作，不替代内部权属文件、数据授权、部署记录、完整实验包或生产监控。

## 公开交付物

- `docs/`：详细回顾、现状、路线、评测和证据边界。
- `data/`：公开可分享的技术领域、课题、研究来源、指标和知识产权台账。
- `assets/visuals/`：面向汇报和评审的 PNG 信息图，每张图同时表达技术主题、当前阶段和未来动作。
- `deliverables/`：合并版 Markdown、Word 和 PDF 报告。
- `scripts/`：公开信息图渲染、报告导出和完整性校验脚本。
