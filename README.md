## 当前台账

- **15 项模型/产品资产**：包含 Sentinel-2 分区处方、遥感质量、地块分割、无人机出苗率/密度、样方矢量化、无人机杂草识别与点喷处方、病虫害/病斑识别、生育期识别、农资与测土报告识别、地块风险评分、智能体和变量作业处方。
- **17 项研究院课题**：保留 01–04、07–19；鸿蒙物联网网关和鸿蒙变量作业控制两项不纳入本版。
- **7 项发明专利事项 + 4 项软件著作权**：每条记录申请号/登记号、公布或证书号、当前法律状态、权利人和对应技术资产。
- **2 项研究成果**：FieldBCQ 与 Wheat-KGCA，分别作为地块评估和知识约束识别的研究依据。
- **7 组配套视觉图**：每组同时提供 PNG 和 SVG，图中标出技术主题、当前阶段和下一步路线。

## 范围边界

- 公开版只写技术名称、产品结果、阶段和证据，不写本地代码位置、仓库位置、分支、提交号、内部地址或配置值。
- 不展开由其他负责人维护的作物模型内容，公开台账只保留本技术负责人负责的其他模型和产品。
- 研究院课题只保留本技术负责人承担的非鸿蒙方向；具体课题编号、研究目标和验收指标见 [课题与路线](docs/11-topics-and-roadmap.md)。
- 专利部分是当前登记台账，不是专利申请教程；“待核实”表示公开材料尚未证明该项已完成登记、实审或产品验收。
